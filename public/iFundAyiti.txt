Page Name:
IFundAyiti - Application Management Dashboard

Page Goal:
Build a centralized application management dashboard where administrators can manage the complete lifecycle of every micro grant application. Instead of creating separate modules for Approved Applicants, Finalists, Winners, and Archived Applicants, the dashboard manages everything from a single Applications page using status-based tabs. Every application moves through different statuses until the application period is completed.

====================================================
IMPORTANT BUSINESS RULES
====================================================

- Applicants do not have user accounts.
- Every application receives a unique Tracking ID after submission.
- Applicants check their application using the Tracking ID (and optionally Date of Birth for verification).
- Every application belongs to exactly one Application Period.
- Maximum requested grant amount is $1000.
- Only admins can modify application data after submission.
- Only admins can change an application's status.
- Approved applications become publicly visible.
- Rejected applications remain private.
- A maximum of five applications can have the Finalist status within a single application period.
- Exactly one application can have the Winner status within a single application period.
- The Winner must be selected from the Finalists.
- When a Winner is selected, the organization transfers funds manually outside the platform.
- Donations always go to the IFundAyiti Program Fund and are never linked to individual applicants.
- All uploaded documents are stored in a single documents array and support image and PDF preview.
- All frontend validation should use Zod, and all data must be validated again on the backend before processing.
